DUNGSTOREGMAIL99

1. Install Node.js 18+.
2. Buka terminal di folder ini.
3. Jalankan: npm install
4. Untuk development: npm start
5. Buka http://localhost:3000/ untuk website publik.
6. Buka http://localhost:3000/owner untuk dashboard Owner.

Default login demo:
Username: DungStoreGmail99
Password: ubah-password-ini

Untuk server sungguhan, WAJIB ubah OWNER_PASS dan SESSION_SECRET melalui environment variable dan gunakan HTTPS.
